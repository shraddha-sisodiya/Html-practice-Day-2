# Admission Form - Day 2 HTML Practice

A simple and responsive admission form built with pure HTML5 as part of my #100DaysOfCode challenge.

## 📸 Live Demo
[View Website](https://shraddha-sisodiya.github.io/html-practice-Day-2/)

## ✨ Features Covered
- HTML5 Form Validation using `required` attribute
- `fieldset` & `legend` for grouping form elements
- Input Types: `text`, `email`, `password`, `number`, `date`
- `select` dropdown for course selection
- `checkbox` for hobbies & `radio` buttons for gender
- Proper `label` tags with `for` attribute
- `Submit` & `Reset` buttons

## 🛠️ Tech Stack
- HTML5

## 🎯 What I Learned
- Structuring complex forms using semantic HTML
- Difference between `checkbox` vs `radio` inputs
- Making forms accessible with labels
- Client-side validation basics

## 🚀 How to Run Locally
1. Download the `index.html` file
2. Open it in any web browser
